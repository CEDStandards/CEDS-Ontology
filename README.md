# CEDS Ontology

The CEDS Ontology is a new way of looking at CEDS. An ontology serves to define entities and the connections between them. In education, we categorize Organizations into types such as a K12 School, a Postsecondary Institution, or an Early Learning Program. We can also describe the relationship that exists between a Person and that Organization such as Enrollment, Assignment, or Employment. The CEDS Ontology builds on the CEDS Integrated Data Store model by not only demonstrating relationships exist between elements through Primary and Foreign Key relationships, but by providing definitions and meaning about those relationships through Object Properties.

The purpose of the Ontology is to describe CEDS at the most granular level possible. From this machine-readable understanding, additional resources can be created such as JSON, JSON-LD, XML, and a host of other machine-readable standards. It also makes it easier to link CEDS to other ontologies and standards using equivalencies (an indication when one standard's element is equivalent to another standard's element), making translation a much more intuitive machine-readable process. We can now indicate where CEDS ends and another standard begins, enabling the adoption of multiple standards in the same ecosystem.

## Current Status

The CEDS Ontology is an actively maintained, production release, now aligned with CEDS Version 14. Each CEDS alignment release updates the Ontology's classes, object properties, and datatype properties to stay in sync with the official, community-approved list of CEDS Elements.

We continue to welcome community review and contributions:

Additional resources may be added over time for reviewing and using the Ontology. Feel free to contribute any you create for community use.

## Versioning

CEDS uses a customized version of [Explicit Versioning](https://github.com/exadra37-versioning/explicit-versioning). To keep the various CEDS Open Source projects in alignment with the CEDS Elements, we replace the concept of "disruptive" releases with "alignment" releases. These releases ensure that the data models stay in sync with the official, community-approved list of CEDS Elements. For the versions available, see the [tags on this repository](https://github.com/CEDStandards/CEDS-Ontology/tags).
